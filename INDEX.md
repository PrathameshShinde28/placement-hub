## 🏃 QUICK COMMANDS

### Start Development
```bash
cd server && npm install && npm run dev     # Terminal 1
cd client && npm install && npm run dev     # Terminal 2
# Visit http://localhost:3000
```

### Build for Production
```bash
cd client
npm run build
# Output in client/dist
```

### Deploy to Heroku
```bash
heroku create your-app
git push heroku main
```
